dashboardรายได้และ Dashboardเลือกช่วงวันที่เพื่อดูภาพรวมรายได้expand_more

Dashboard สรุปจำนวนพัสดุ บ้านซ้ำ เงินหัก RTS และ Net Incentive ตามช่วงวันที่ที่เลือก ใช้ตัวเลือก วันนี้, 7 วัน, 30 วัน, รอบตัดเงิน หรือกำหนด Custom Range โดยเลือกวันที่เริ่มต้นและวันที่สิ้นสุด

historyรายการย้อนหลัง (History)ค้นหา กรอง แก้ไข และลบรายการexpand_more

เปิด History เพื่อดูรายการคำนวณที่บันทึกไว้ ใช้ Search และ Filter แยก 2W / 4W ได้ เปิดรายการเพื่อแก้ไข และใช้ Delete เมื่อต้องการลบรายการที่ไม่ถูกต้อง

receipt_longอ่านผลลัพธ์การคำนวณเข้าใจ Gross, Deduction และ Net Incentiveexpand_more

Gross / รายได้รวมรายได้ก่อนหักรายการ

Same Address / บ้านซ้ำจำนวนพัสดุบ้านซ้ำตามข้อมูลที่กรอก

Deduction / เงินหักยอดเงินหักตามกฎของระบบ

Net Incentive / คงเหลือรายได้หลังหักรายการที่เกี่ยวข้อง

manage_accountsProfile และ Settingsข้อมูลส่วนตัว Theme และการตั้งค่าexpand_more

Profile รองรับ ชื่อ-นามสกุล, Hub, ตำแหน่ง, Employee ID, Driver ID และ Email ตามข้อมูลที่ระบบมี Settings ใช้สลับ Theme แบบ Light, Dark หรือ System และจัดการตัวเลือกของแอป

backupBackup / Restore / Exportป้องกันข้อมูลหายและนำข้อมูลไปใช้ต่อexpand_more

ระบบนี้ไม่มีไฟล์ Backup แยก: Profile และรายการจะ Sync กับ Account เมื่อ Login และเชื่อมต่อระบบได้ หากเปลี่ยนเครื่องให้ติดตั้งแอปแล้ว Login Account เดิมเพื่อดึงข้อมูลกลับตามระบบจริง ส่วน Export ใช้ส่งออกผลคำนวณเป็น PDF หรือ Excel จากหน้าคำนวณ

verified_userLicenseตรวจ Status, วันเริ่ม, วันหมดอายุ และ Planexpand_more

ตรวจสอบ License Status, Start Date, Expiry Date และ Plan ได้จาก Settings: Trial ใช้ตามช่วงทดลองจริง, Monthly ใช้ตามระยะเวลา 30 วัน และ Lifetime ไม่หมดอายุ หากหมดอายุให้เลือกซื้อสิทธิ์หรือติดต่อผู้พัฒนาผ่าน LINE

helpFAQคำตอบสำหรับปัญหาที่พบบ่อยexpand_more
คำนวณแล้วรายได้ไม่ตรง ทำอย่างไร?

ตรวจสอบ 2W / 4W, Zone, จำนวนส่ง, บ้านซ้ำ, RTS และวันที่ให้ตรงกับงานจริง

ข้อมูลหายทำอย่างไร?

ตรวจสอบว่า Login Account เดิม และตรวจสอบ Backup ที่มีอยู่

เปลี่ยนเครื่องทำอย่างไร?

ติดตั้งแอป → Login → Restore ตามระบบจริง

License หมดอายุทำอย่างไร?

กดซื้อสิทธิ์ / ต่ออายุ หรือกดติดต่อผ่าน LINE

ติดต่อผู้พัฒนาอย่างไร?

กดปุ่ม LINE ในหน้านี้หรือหน้า License
