วิธี build และติดตั้งอยู่ที่ไฟล์นี้ แบบฟอร์มติ๊กบนเครื่องอยู่ที่ [V2.0_MANUAL_TEST_CHECKLIST.md](V2.0_MANUAL_TEST_CHECKLIST.md)

ใช้กับ branch `feature/v2.0` commit `abeffa410eda8c2287537d629f337261a3d63d8b` หรือลูกของ commit นี้ที่ไม่มี diff นอกเอกสาร QA

ห้ามแก้โค้ดแอป, calculation engine, tier/rate, license, auth, Supabase, GPS, download analytics, signing หรือ package `com.cw.incentive` เพื่อให้เทสผ่าน ห้าม merge เข้า `main`

ถ้า `adb devices` ว่าง หรือไม่มี Android SDK: บันทึก **BLOCKED** แล้วหยุด

## 1. เครื่องและเครื่องมือ

- เครื่อง Android จริง เปิด USB debugging ใช้เครื่องทดสอบที่ลบแอปได้
- Debug APK เซ็นด้วย debug certificate จะติดตั้งทับแอป production ที่เซ็นคนละใบไม่ได้ อย่าลบแอปบนเครื่องผู้ใช้จริงเพื่อบังคับติดตั้ง
- Node 22, npm 10, JDK 21
- Android SDK Platform 35, Build Tools 35.0.0, Platform Tools

```bash
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME="$HOME/Android/Sdk"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH"
adb devices -l
```

ต้องเห็น `device` ไม่ใช่ `unauthorized` หรือรายการว่าง

Diff ของไฟล์เหล่านั้นต้องว่าง ถ้า `android/app/build.gradle` เปลี่ยน ตรวจว่ามีแค่ `versionCode 11` และ `versionName 2.0.0` และ `applicationId` ยังเป็น `com.cw.incentive`

```bash
npm ci

npm run check:baseline
```

## 3. Build และติดตั้ง debug เท่านั้น

ไม่รัน `android:release` และไม่ตั้ง `CW_KEYSTORE_*` ในรอบนี้

```bash
npm run android:debug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

```bash
aapt dump badging android/app/build/outputs/apk/debug/app-debug.apk | grep -E "package:|versionCode|versionName"
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
adb shell dumpsys package com.cw.incentive | grep -E "versionName|versionCode"
```

ต้องได้ package `com.cw.incentive`, `versionName=2.0.0`, `versionCode=11`

ทางเลือกบนเครื่องที่ต่ออยู่แล้ว ไม่ใช่ตัวแทนการตรวจหน้าจอ:

```bash
cd android && ./gradlew connectedDebugAndroidTest --no-daemon
```
