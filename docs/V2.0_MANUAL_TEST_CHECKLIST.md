# TBS Incentive V2.0 — เช็กลิสต์ทดสอบมือ

สาขา `feature/v2.0` แอป `com.cw.incentive` เวอร์ชัน `2.0.0` (`versionCode 11`)

วิธี build และติดตั้งอยู่ที่ [V2.0_DEVICE_QA_STEPS.md](V2.0_DEVICE_QA_STEPS.md) เอกสารนี้เป็นแบบฟอร์มให้ติ๊กบนเครื่องเท่านั้น

ห้ามแก้โค้ด ห้าม merge เข้า `main` ถ้าข้อใดทำไม่ได้ให้ใส่ BLOCKED แล้วไปข้อถัดไปที่ยังทำได้ ถ้าติดตั้งแอปไม่ได้ให้หยุดทั้งใบ

## ก่อนแตะหน้าจอ

- [ ] Package เป็น `com.cw.incentive`
- [ ] `versionName` เป็น `2.0.0`
- [ ] `versionCode` เป็น `11`
- [ ] ติดตั้งบนเครื่องทดสอบ ไม่ใช่เครื่องที่ต้องเก็บข้อมูล production
- [ ] ไม่ได้ถอนแอป production เพื่อบังคับติดตั้ง debug

## เข้าสู่ระบบและสิทธิ์

- [ ] หน้าเข้าสู่ระบบเปิดได้ ช่องอีเมล รหัสผ่าน และปุ่มกดได้
- [ ] บัญชีทดสอบเดิมเข้าได้
- [ ] ถ้ายังไม่มีแพ็กเกจ เกตเลือกแพ็กเกจแสดงเอง และไม่เริ่มทดลองใช้เอง
- [ ] สลับ Light / Dark บนเกตนี้ตัวหนังสือยังอ่านได้

## หน้าหลัก

- [ ] เห็นคำว่า แดชบอร์ดรายได้
- [ ] เห็นคำว่า รายได้ 7 วัน
- [ ] เห็นคำว่า กิจกรรมล่าสุด
- [ ] ตัวเลขสุทธิ อ่านได้ ไม่ทับไอคอน
- [ ] ไม่มีคำว่า Income Dashboard, 7-Day Income หรือ Recent Activity

## ช่วงวันที่

- [ ] วันนี้
- [ ] 2W
- [ ] 4W กลางเดือน
- [ ] 4W สิ้นเดือน
- [ ] เลือกวันเริ่มและวันสิ้นสุดเอง แล้วยกเลิกได้
- [ ] ใช้ช่วงวันที่แล้ว ตัวเลขหน้าหลักเปลี่ยนตามช่วง

## เครื่องคิดเลข

- [ ] เปิดแท็บคำนวณได้
- [ ] 2W เหลือช่องส่งสำเร็จช่องเดียว
- [ ] 4W มี Size L และ Size S
- [ ] ช่องโซนเปิดชีตเลือกได้ และกด Back หรือแตะนอกชีตแล้วชีตปิด
- [ ] ช่องว่างหรือค่าติดลบแสดงข้อความผิด และไม่โชว์ผลหลอกว่าคำนวณสำเร็จ
- [ ] คีย์บอร์ดตัวเลขไม่บังปุ่มคำนวณถาวร เลื่อนหน้าแล้วถึงปุ่ม

ใส่ RTS = 0 ทั้งสองแถว

- [ ] 2W, Zone 1, ส่งสำเร็จ 70, บ้านซ้ำ 10 ได้รวม 632.00 หัก 15.00 คงเหลือ 617.00
- [ ] 4W, Zone 1, Size S 5, Size L 1, บ้านซ้ำ 0 ได้รวม 37.00 คงเหลือ 37.00
- [ ] ป้ายอัตราบ้านซ้ำเป็น -1.5 เมื่ออยู่ 2W และ -2.5 เมื่ออยู่ 4W

## รายการ โปรไฟล์ ตั้งค่า

- [ ] รายการว่าง หรือรายการเดิม อ่านได้ ไม่ล้นขอบ
- [ ] ช่องค้นหารายการพิมพ์แล้วล้างได้
- [ ] โปรไฟล์เปิดได้ ยังไม่บังคับบันทึกถ้าไม่ได้แก้
- [ ] ตั้งค่าแสดง V2.0.0
- [ ] เปิดรายละเอียดการทำจ่ายได้
- [ ] จากหน้ารายละเอียดกด Back กลับตั้งค่า ไม่เด้งออกจากแอป
- [ ] สลับ Light แล้ว Dark อีกครั้ง ทั้งหน้าหลัก เครื่องคิดเลข และตั้งค่า

## จอและการนำทาง

- [ ] ที่ความกว้างประมาณ 360 แท็บล่าง 5 ปุ่มอ่านได้ ไม่ล้นแนวนอน
- [ ] ปุ่มหลักสูงพอประมาณนิ้ว ไม่ชิดขอบจนดันยาก
- [ ] ปัดจากขอบหรือกด Back ปิดชีตก่อน แล้วค่อยย้อนหน้าย่อย
