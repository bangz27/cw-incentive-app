The physical Windows ADB attempt on `vivo_1935` / Android 10 captured the exact Android Package Manager result:

```text

Performing Streamed Install
adb.exe: failed to install C:\Users\spxhub2955\Downloads\TBS-Incentive-v1.9.0-release.apk: Failure [INSTALL_FAILED_UPDATE_INCOMPATIBLE: Package com.cw.incentive signatures do not match previously installed version; ignoring!]
```

The physical device evidence confirms that a standard Android update is not compatible: the package identity is the same but the signing certificates differ. Android requires the update signer to match the installed signer, unless an accepted signing lineage is present; no such lineage is present in the inspected V1.9.0 artifact.

**TEST A: SIGNING MIGRATION EXCEPTION — VERIFIED**

This is a package-signing compatibility limitation, not a functional defect in Package Selection, Trial Flow, Calculation Engine, or License Logic. V1.9+ must continue using the permanent D8:B2 certificate. Re-signing V1.9.0 with the old E7:CA certificate, creating a new key, changing the alias, or changing the package name is prohibited.

### Backend Compatibility

The deployed Supabase project is healthy and contains migration `20260928150214` (`persistent_trial_activation`). The deployed `public.app_licenses` table includes `trial_started_at`, `trial_ends_at`, and `trial_used_at`, with `user_id` as the primary key and RLS enabled.

- `get_my_license_status()` is `SECURITY DEFINER`, filters by `user_id = auth.uid()`, calculates status and remaining time from backend `now()`, and returns at most one row.
- `start_my_trial()` is `SECURITY DEFINER`, requires an authenticated `auth.uid()`, locks the account row with `FOR UPDATE`, creates a 14-day Trial using backend timestamps, and rejects a previously used Trial.
- `profiles` and `incentive_records` are RLS-protected and keyed by `user_id`; `supabase-auth.js` upserts local profile/history and restores account data after login.
- License cache in LocalStorage is scoped to the authenticated user and is a temporary UX cache; it is not the entitlement source of truth.
- Clear Data/Reinstall recovery path: **PASS by backend design and Emulator C result reported by the user**; a physical-device result is not available.

Backend entitlement assessment: **PASS**.
